# 공유용 견적서 자동 생성 스킬

## 무엇을 하는가
사용자가 채팅에서 알려준 견적 정보를 받아, 표준 견적서 엑셀 파일을 생성하고
다운로드 가능한 위치(`/mnt/user-data/outputs/`)에 저장한다.

## 파일 구조
```
quote-light/
├── SKILL.md
├── assets/
│   └── quote_template.xlsx       ← 빈 견적서 템플릿 (이미 생성됨)
└── scripts/
    ├── create_template.py        ← 빈 템플릿을 재생성 (디자인 수정 시만)
    └── fill_quote.py             ← 템플릿에 데이터 채우는 핵심 스크립트
```

## 엑셀 양식 구조

### 0.입력 시트
사용자가 채우거나, 스크립트가 자동 채우는 시트.

**고객사 정보 (5~7행)**:
법인명, 담당자, 발행일, 주소, 연락처, 유효기간, 견적번호, 이메일, 담당부서

**견적 항목 (10~15행, 최대 5개)**:
- A: # (순번, 자동)
- B:E: **제품명** (병합, 직접입력)
- F: 수량 (직접입력)
- G: 단가 (원, 직접입력)
- H: 공급가액 (자동: `수량 × 단가`)
- I:K: 비고 (병합, 직접입력)

**합계 (17행)**: H17 = SUM(H11:H15), VAT 별도

### 1.견적서 시트
0.입력 시트를 참조해 자동 채워지는 견적서. 우측 "공급자" 박스는 (주)샘플로 하드코딩된
**자리표시자**이다 — 실제 사용 전 본인 회사 정보로 교체 필요 (자세한 내용은 아래
"공급자 정보 수정" 섹션 참고).

## 워크플로우

### "자동 견적 생성!" 트리거 (빈손으로 시작)

사용자가 정확히 **"자동 견적 생성!"** 또는 그와 비슷한 빈손 시작 신호("견적서
만들어줘", "새 견적서" 등 — 별도 정보 없이)를 보내면, 정보를 하나씩 묻지 말고
아래 양식을 그대로 보여준다. 사용자가 알고 있는 만큼 한 번에 던져주는 스타일이므로
번거롭게 다단계로 묻지 말 것.

**Claude가 보여줄 양식 (그대로 복붙해서 사용)**:

```
견적서 생성에 필요한 정보입니다. 알고 계신 항목만 채워서 한 번에 보내주세요.
모르거나 비워둘 항목은 그냥 빈칸으로 두시면 됩니다.

━━━ 고객사 정보 (공급받는자) ━━━
- 법인명: (필수)
- 담당자:
- 연락처:
- 이메일:
- 주소:
- 견적번호:
- 발행일: (없으면 오늘 날짜로)
- 유효기간: (없으면 "발행일로부터 30일")

━━━ 공급자 정보 (자사) ━━━
- 법인명: (없으면 "(주)샘플"로 표기)
- 등록번호:
- 대표자:
- 주소:
- 담당부서:
- 연락처:

━━━ 제품 항목 (1~5개, 형식: 제품명 | 수량 | 단가 | 비고) ━━━
1.  (필수: 제품명, 수량, 단가)
2.
3.
4.
5.

━━━ 저장 위치 (선택) ━━━
- 경로: (없으면 기본 위치)
```

**최소 필수 정보**:
- 고객사 법인명
- 제품 1개 이상 (제품명 + 수량 + 단가)

이것만 있으면 견적서 생성 가능. 나머지는 다 비어도 됨.

### 일반 워크플로우 (정보가 이미 주어진 경우)

사용자가 처음부터 정보를 어느 정도 주고 시작한 경우(예: "예시고객에 노트북 받침대
50개 견적서 만들어줘") 아래 절차를 따른다.

#### 1단계: 사용자 입력 파싱
사용자가 자연어로 던지는 정보를 `customer` + `items` JSON 구조로 변환한다.

**예시 입력**: "예시고객에 노트북 받침대 50개, 단가 35,000원으로 견적서 만들어줘"

**파싱 결과**:
```json
{
    "customer": {"company": "(주)예시고객"},
    "items": [{
        "product": "노트북 받침대",
        "quantity": 50,
        "unit_price": 35000
    }]
}
```

#### 2단계: 부족한 정보 확인
필수 정보가 빠져있어도 빈칸으로 채워 생성해도 되지만, **있으면 좋은 정보**가 빠졌을
때는 한 번에 모아서 짧게 물어본다. 너무 자주 묻지 말 것.

**최소 필요**: 회사명, 제품 최소 1개, 수량, 단가
**자주 누락되는 것**: 담당자명, 연락처, 견적번호

질문 없이 만들 수 있으면 그냥 만들고, 사용자가 수정 요청하면 그때 채운다.

#### 3단계: JSON 파일 생성 후 스크립트 실행
```bash
# 1) 입력 JSON을 임시 파일로 저장
cat > /tmp/quote_input.json << 'EOF'
{...파싱된 JSON...}
EOF

# 2) 스크립트 실행 (스킬 폴더에서)
python3 <SKILL_DIR>/scripts/fill_quote.py \
    /tmp/quote_input.json \
    <출력경로>/견적서_<회사명>_<YYMMDD>.xlsx
```

**출력 경로 선택**:
- Claude.ai 환경: `/mnt/user-data/outputs/` (자동 다운로드 위치)
- Claude Code 환경: 사용자가 지정한 경로, 또는 현재 작업 디렉토리, 또는 `~/Downloads/`

#### 4단계: 사용자에게 파일 전달
- Claude.ai: `present_files` 도구로 다운로드 가능하게 제시
- Claude Code: 생성된 파일의 절대 경로를 알려준다

## 입력 JSON 스키마

```json
{
    "customer": {                          // 공급받는자 (0.입력 시트로 들어감)
        "company":        "string",   // 법인명 (필수)
        "address":        "string",   // 주소
        "contact_person": "string",   // 담당자
        "phone":          "string",   // 연락처
        "email":          "string",   // 이메일
        "quote_number":   "string",   // 견적번호 (없으면 비움)
        "issue_date":     "YYYY-MM-DD", // 발행일 (없으면 TODAY())
        "validity":       "string",   // 유효기간 (기본: 발행일로부터 30일)
        "department":     "string"    // 담당부서
    },
    "supplier": {                          // 공급자 (1.견적서 시트, 옵션)
        "company":             "string",  // 법인명 (기본 "(주)샘플")
        "registration_number": "string",  // 등록번호
        "ceo":                 "string",  // 대표자
        "address":             "string",  // 주소
        "department":          "string",  // 담당부서
        "phone":               "string"   // 연락처
    },
    "items": [                             // 제품 항목 (최대 5개)
        {
            "product":    "string",   // 제품명 (자유 입력)
            "quantity":   100,        // 수량
            "unit_price": 35000,      // 단가 (원)
            "note":       "string"    // 비고
        }
    ]
}
```

`supplier` 객체는 옵션이다. 생략하거나 일부 필드만 채워도 동작하며, 누락된 필드는
템플릿 기본값(법인명 "(주)샘플", 나머지 빈칸)이 유지된다.

## 출력 파일명 규칙
`견적서_<회사명>_<YYMMDD>.xlsx`

회사명에 공백·특수문자가 있어도 그대로 사용 가능 (Mac/Windows 파일명 호환).

예: `견적서_예시고객_260512.xlsx`

## 자동 계산되는 항목 (사용자에게 알려줄 것)

생성 후 결과를 알려줄 때 다음 정보를 함께 보여주면 좋다:

- **공급가액** = 수량 × 단가
- **합계** = 모든 항목 공급가액 합 (VAT 별도)

## 공급자 정보 수정

견적서 시트(`1.견적서`) 우측 "공급자" 박스는 **법인명만 "(주)샘플"** 로 들어가 있고
나머지 필드(등록번호, 대표자, 주소, 담당부서, 연락처)는 **빈칸**이다. 사용자가 엑셀에서
직접 채워 사용한다.

특정 회사 정보로 고정해 두고 싶다면 두 가지 방법:

### 방법 A: 템플릿을 재생성 (영구 변경)
`scripts/create_template.py` 의 `build_quote_sheet` 함수 안 `info_rows` 변수
편집 → `python3 scripts/create_template.py assets/quote_template.xlsx` 실행.

`info_rows` 의 우측 값(다섯 번째 컬럼)을 본인 회사 정보로 바꾸면 된다.

### 방법 B: 생성된 견적서 파일에서 직접 수정 (개별 견적서만)
견적서 시트 H5~H10 셀을 엑셀에서 직접 편집.

## 자주 발생하는 케이스와 대응

### 케이스 1: 회사명만 있고 나머지가 다 없음
회사명만 입력하고 빈 견적서를 생성한다. "나머지 정보는 엑셀 0.입력 시트에 직접 입력하면
견적서 시트에 자동 반영됩니다"라고 안내.

### 케이스 2: 단가를 모름
단가 없이 생성하되, "단가는 비워뒀습니다. 0.입력 시트 G열에 입력하면 공급가액과 합계가
자동 계산됩니다"라고 알려준다.

### 케이스 3: 항목이 5개 초과
앞 5개만 입력하고 사용자에게 알린다. 더 많은 항목이 필요하면 별도 견적서로 나눠
만들도록 안내, 또는 `create_template.py`에서 행 수를 늘리도록 안내.

### 케이스 4: 사용자가 디자인 수정 요청
`scripts/create_template.py`를 편집하고 다시 실행하면
`assets/quote_template.xlsx`가 재생성된다. 그 후 `fill_quote.py`를 다시 실행.

## 의존성
- Python 3.8+
- openpyxl

## 트러블슈팅

### 수식 결과가 빈칸으로 보임 (Excel에서 열었을 때)
openpyxl로 만든 파일은 수식만 들어있고 계산된 값은 저장되지 않는다.
Excel/LibreOffice에서 열면 자동 재계산되므로 정상이다. 미리 계산된 값이 필요하면:
```bash
python3 /mnt/skills/public/xlsx/scripts/recalc.py output.xlsx
```

### 한글 깨짐
폰트는 "맑은 고딕"으로 지정됨. Mac에서는 "AppleGothic" 등으로 자동 대체되지만
한글 표시에는 문제 없다.
